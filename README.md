# Life Advisors — Website Architecture Wireframe

Client-review presentation of the proposed Life Advisors website architecture (desktop wireframe). This is a site plan for review, not the production website.

## Live preview

https://whatwedobest.github.io/LIF_LifeAdvisors_LifeAD/

## What’s included

- Homepage architecture (hero through footer)
- Section labels and approximate desktop heights
- Meta campaign landing-page outlines
- Wireframe legend

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080
